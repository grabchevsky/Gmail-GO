# Gmail Go

Репозиторий с APK-файлом облегченной версии Gmail для Android.

## Что это такое

Gmail Go — это официальное приложение от Google, созданное специально для смартфонов с малым объемом памяти (Android Go Edition) и медленным интернетом. Оно занимает мало места, быстро работает и потребляет меньше трафика.

Официальная поддержка приложения давно прекращена, и оно может быть недоступно для скачивания в Google Play на новых устройствах.

## Как установить

1. Перейдите в раздел **[Releases](https://github.com/grabchevsky/Gmail-GO/releases)**.
2. Скачайте APK-файл `GmailGo.apk`.
3. Разрешите установку из неизвестных источников в настройках вашего телефона.
4. Откройте скачанный файл и установите приложение.

## Системные требования

*   **ОС:** Android 8.1 (Oreo) или новее.
*   **Память:** Приложение занимает около 10–15 МБ.

## Примечание

Это архивная копия. Приложение больше не обновляется, но может работать на старых устройствах, где обычный Gmail работает медленно или не устанавливается.
